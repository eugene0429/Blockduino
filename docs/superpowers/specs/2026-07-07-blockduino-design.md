# Blockduino 설계 문서

날짜: 2026-07-07
상태: 사용자 승인 대기

## 1. 개요

초중등 학생용 블록 코딩 아두이노 프로그램. 한글 블록을 드래그해서 조립하면
Arduino C++ 코드가 실시간 생성되고, 업로드 버튼 하나로 컴파일 → Uno R3 보드에
USB 업로드까지 완료된다.

- 배포: 윈도우 설치파일(.exe). 인터넷 없는 학교 PC에서 완전 오프라인 동작
- 개발: macOS에서도 실행/테스트 가능 (Electron 크로스 플랫폼)
- 대상 보드: Arduino Uno R3 (정품 및 CH340 호환보드)

## 2. 화면 구성

```
┌────────────────────────────────────────────────┐
│  [프로젝트명]   [열기] [저장]  [보드포트 ▼] [⬆ 업로드] │
├──────────┬──────────────────────┬──────────────┤
│ 블록 팔레트 │                      │  생성된 코드   │
│          │    블록 작업 공간       │  (C++ 미리보기)│
│ ▸ 기본    │                      │              │
│ ▸ 입출력   │   (드래그 & 드롭)      │              │
│ ▸ 센서    │                      │              │
│ ▸ 모터    │                      │              │
│ ▸ 논리/반복 │                      │              │
├──────────┴──────────────────────┴──────────────┤
│  상태바: 컴파일 중... / 업로드 완료! ✓              │
└────────────────────────────────────────────────┘
```

- 3단 레이아웃: 좌측 블록 팔레트, 중앙 작업 공간, 우측 생성 코드 미리보기(읽기 전용)
- 상단 툴바: 프로젝트명, 열기/저장, 포트 선택 드롭다운, 업로드 버튼
- 하단 상태바: 컴파일/업로드 진행 상황과 결과를 한글로 표시

## 3. 블록 구성 (한글)

| 카테고리 | 블록 |
|---------|------|
| 기본 | 시작하면(setup), 계속 반복(loop), 기다리기(delay, 초/밀리초) |
| 입출력 | LED 켜기/끄기, 디지털 읽기/쓰기, 아날로그 읽기/쓰기(PWM), 버튼 눌림, 부저 소리내기(음계/멜로디) |
| 센서 | 초음파 거리(HC-SR04), 온습도(DHT11), 조도 센서(CDS 포토레지스터, 아날로그) |
| 모터/출력 | 서보모터 각도(Servo), LCD(I2C 16x2) 문자 출력/지우기 |
| 논리/반복/변수 | Blockly 기본 제공 블록의 한글판 (만약~라면, 반복, 비교, 연산, 변수) |

- 핀 번호는 블록의 드롭다운으로 선택 (Uno 핀 범위로 제한: D0–D13, A0–A5)
- 잘못된 블록 조합은 블록 연결 규칙(타입 체크)으로 사전 차단

## 4. 기술 구조

- **Electron + Blockly**: 블록 편집기와 UI. 커스텀 블록마다 대응하는 Arduino
  C++ 코드 생성기를 작성. Blockly 워크스페이스 변경 시 코드 미리보기 실시간 갱신
- **arduino-cli 내장**: 설치파일에 arduino-cli 바이너리 + AVR 보드 코어 +
  필요 라이브러리(DHT sensor library, Servo, LiquidCrystal_I2C 등)를 미리 포함
  → 오프라인 컴파일/업로드
- **코드 생성 구조**: 블록 → setup()/loop() 본문 + 필요한 #include/전역 선언을
  자동 수집 (예: 서보 블록 사용 시 `#include <Servo.h>`와 Servo 객체 선언 추가)
- **포트 자동 감지**: arduino-cli board list로 USB 연결된 Uno 포트를 주기적으로
  감지해 드롭다운에 표시. 보드 1개면 자동 선택
- **CH340 드라이버 안내**: 국내 교육용 호환보드 대부분이 CH340 칩 사용.
  드라이버 미설치로 포트가 안 보이는 상황을 감지하면 설치 안내 표시
- **프로세스 구조**: 렌더러(블록 UI) ↔ 메인 프로세스(파일 I/O, arduino-cli 실행)
  는 IPC로 통신. 컴파일/업로드는 메인 프로세스에서 child process로 실행

## 5. 배선 안내 그림

- 작업 공간에서 부품 블록(LED, 버튼, 부저, 초음파, DHT11, 조도 센서, 서보,
  LCD)을 사용하면 해당 부품의 브레드보드 연결 그림을 볼 수 있음
- 표시 위치: 우측 패널을 "코드 / 배선" 탭으로 전환. 배선 탭에는 현재 사용 중인
  부품들의 연결 그림 목록을 표시
- 그림은 부품별로 미리 제작한 정적 이미지(SVG). 블록에서 선택한 핀 번호를
  그림 위 라벨로 표시 (예: "신호선 → D7")
- 동작 시뮬레이션(가상 실행)은 포함하지 않음 — 9절 참고

## 6. 프로젝트 저장

- 블록 배치를 `.bdn` 파일로 저장/열기 (내부 포맷: Blockly serialization JSON)
- 단일 파일 — 학생이 USB 메모리로 들고 다닐 수 있음
- 저장하지 않은 변경이 있을 때 닫기/열기 시 확인 대화상자

## 7. 오류 처리

- 업로드 실패를 학생 눈높이 한글 메시지로 변환:
  - 포트 없음 → "아두이노가 연결되어 있는지 확인해 주세요"
  - 드라이버 없음 → CH340 드라이버 설치 안내
  - 업로드 중 뽑힘/통신 실패 → "USB 케이블을 다시 연결하고 시도해 주세요"
- 컴파일 오류는 블록 단계에서 잘못된 조합을 차단해 원칙적으로 발생하지 않도록 함.
  그래도 발생하면 원문 로그를 "자세히 보기"로 접어서 제공

## 8. 테스트

- 코드 생성기: 블록 조합 → 기대 C++ 출력 스냅샷 테스트 (Node 단위 테스트)
- 컴파일 검증: 대표 블록 조합별 생성 코드를 arduino-cli compile로 실제 컴파일
- 업로드: 실기기(Uno R3) 수동 테스트 체크리스트
